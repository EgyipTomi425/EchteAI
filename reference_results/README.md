# Reference results

Results of the run reported in the article, produced by the pipeline of this repository on the system
described in `environment.json` (NVIDIA H200, driver 590.48.01, CUDA 12.8, TensorRT 11.3.0.99,
ModelOpt 0.47.0). A new run writes the same files under `results/`; compare them with

```bash
python scripts/40_compare_results.py            # results/tables against reference_results/tables
```

| Directory | Content | Produced by |
|---|---|---|
| `tables/*.csv` | every table behind the numbers of the article (accuracy, benchmark, energy, deviation statistics, risk, robustness, selective precision, calibration, fleet scenario, …) | `scripts/04`–`41` |
| `tables/tex/` | the LaTeX tables of the manuscript | `scripts/13_tables.py` |
| `tables/gpu_info.json` | GPU recorded by the benchmark | `scripts/04_benchmark.py` |
| `figures/*.pdf` | all figures of the manuscript | `scripts/12_figures.py` |
| `selective/*_layers.csv` | per-layer deviation of every selective-precision variant | `scripts/10_selective.py` |
| `risk/*.csv` | per-image and per-detection deviation and error data (image- and detection-level analyses) | `scripts/07_risk.py` |
| `calibration/*_thresholds.json` | clipping ranges of the order-independent entropy calibration | `scripts/34_global_entropy.py` |
| `qualitative/*.json` | the automatically selected qualitative example | `scripts/28_qualitative.py` |

Not included (regenerated by the pipeline, about 21 GB): ONNX models, TensorRT engines, stored detections,
layer activations and logs.
